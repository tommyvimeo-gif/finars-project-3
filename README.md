# FIN ARS – Arhitekturni biro

Modern responsive website for **FIN ARS d.o.o.** architectural studio (Zagorje ob Savi, Slovenia).

## Features
- Apple-inspired clean design
- Fully responsive (mobile + desktop)
- Animated hero background with architectural photography
- Project gallery with lightbox zoom
- Pages: Home, Projects, About, Services, Contact
- Contact form + company details

## Live preview
Open `index.html` in a browser or deploy to any static host (GitHub Pages, Netlify, Vercel…).
